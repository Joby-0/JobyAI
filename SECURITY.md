# Security policy

JobyAI is under active development. The following policy describes which
versions receive security fixes and how to report a suspected vulnerability.

## Supported versions

| Version | Supported |
| --- | --- |
| Current development version on the default branch | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues or pull
requests. Use GitHub's **Report a vulnerability** feature on this repository to
send a private report. If that option is unavailable, open a private security
advisory for this repository if GitHub permits it.

Include the affected version or commit, the relevant component, steps to
reproduce the issue, and potential impact. Avoid including real credentials,
personal data, or other secrets in the report.

The maintainers will acknowledge reports as soon as practical and coordinate
any fix and disclosure with the reporter. Please allow time for an issue to be
investigated and resolved before sharing vulnerability details publicly.
